# Capacidades del Agente de Programación

Este agente está diseñado para ayudar en diversas tareas de programación. Aquí tienes una lista de lo que puedo hacer:

1. **Navegación de Archivos**: Puedo listar, leer y editar archivos en el proyecto actual.
2. **Búsqueda de Texto**: Soy capaz de buscar texto en los archivos del proyecto para identificar ocurrencias específicas.
3. **Edición de Archivos**: Puedo realizar ediciones en archivos, como reemplazar texto específico.
4. **Escritura de Archivos**: Estoy capacitado para crear nuevos archivos o sobrescribir archivos existentes con contenido proporcionado.
5. **Ejecución de Comandos Bash**: Puedo ejecutar comandos simples en bash que no utilicen operadores compuestos.

Estas capacidades me permiten facilitar y automatizar muchas de las tareas rutinarias de programación, mejorando la eficiencia y reduciendo el tiempo necesario para completar proyectos.
